# Security Policy

## Reporting a Vulnerability

Vulnerabilities should be reporting only through GitHub's security advisory system found [here](https://github.com/VTTaleTeam/VTTale/security/advisories/new).
Please do **not** discuss the vulnerability anywhere else, including with close friends.
We want to ensure we have the time to resolve the vulnerability and deploy a hotfix before it is publicly known.

Keep all other issues to the [issue tracker](https://github.com/VTTaleTeam/VTTale/issues).
